# Contributing to 1520ai Repositories

**Status:** Active
**Scope:** Organization default — shown on any 1520ai repository that does not have its own `CONTRIBUTING.md`
**Audience:** Contributors to 1520ai repositories

---

## Why You Are Seeing This

GitHub displays this file on every 1520ai repository that has not added a `CONTRIBUTING.md` of its own. It is a placeholder, not a process imposed on your project.

---

## Your Repository Sets Its Own Workflow

Each product team decides how it branches, reviews, tests, and releases.

To document that workflow, add a `CONTRIBUTING.md` to your repository (in the root, `docs/`, or `.github/`). Your file replaces this one automatically for that repository.

Until a repository has its own file, follow the conventions its maintainers already use.

---

## What Applies Everywhere

Two organization-level documents apply to every repository regardless of local workflow:

- **[SECURITY.md](SECURITY.md)** — how security issues are reported and escalated. Report security issues; do not quietly fix or work around them.
- **[docs/engineering-operating-standards.md](docs/engineering-operating-standards.md)** — the organization's engineering baseline.

---

## Changing Organization Governance Documents

Changes to this repository (`1520ai/.github`) follow a stricter process, described in [docs/governance-contributing.md](docs/governance-contributing.md).
